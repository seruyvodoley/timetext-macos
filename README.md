# ТаймТекст

Простое приложение для локальной расшифровки видео и аудио на macOS. Перетащите файл в окно, выберите язык и формат результата. Таймкоды автоматически добавляются к каждому фрагменту речи. Нужен macOS 27 или новее и Mac с Apple Silicon.

## Для пользователя

Скачайте `ТаймТекст-1.0.0-arm64.dmg` со страницы Releases, откройте образ и перетащите приложение в папку «Программы». При первом запуске macOS может попросить подтвердить открытие: сборка пока не нотарифицирована Apple, потому что для нотарификации нужен платный Developer ID разработчика. Если появится предупреждение, нажмите правой кнопкой по приложению в «Программах» → «Открыть» → «Открыть».

Поддерживаются распространённые видео и аудиоформаты: MP4, MOV, MKV, WebM, AVI, MP3, WAV, M4A, AAC, FLAC и OGG. Распознавание выполняется локально на Mac; исходный файл никуда не отправляется. TXT и Word сохраняются рядом с исходником. Для каждого пункта результата указано время начала фрагмента.

## Сборка

Нужны Xcode Command Line Tools, Homebrew, `ffmpeg` и `whisper.cpp`:

```sh
brew install ffmpeg whisper-cpp
./Packaging/build_app.sh
```

Скрипт скачивает модель, проверяет SHA-256, собирает `.app`, включает используемые Homebrew библиотеки и подписывает приложение локальной ad-hoc подписью. Для финального релиза запускайте на macOS 27 / Apple Silicon.

- Модель `large-v3-turbo-q5_0`: [ggml-org/whisper.cpp на Hugging Face](https://huggingface.co/ggerganov/whisper.cpp), модель семейства OpenAI Whisper, MIT.
- FFmpeg: LGPL/GPL согласно включённым сборкой компонентам. Исходный код и лицензии доступны на [официальном сайте FFmpeg](https://ffmpeg.org/download.html) и в [официальном репозитории](https://github.com/FFmpeg/FFmpeg). Эта сборка использует пакет Homebrew FFmpeg 9.0.2_1.
- Модель можно скачать отдельно: [large-v3-turbo-q5_0.bin](https://huggingface.co/adidsh/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin). SHA-256: `394221709cd5ad1f40c46e6031ca61bce88931e6e088c188294c6d5a55ffa7e2`.

ТаймТекст предоставляется «как есть». Точность распознавания зависит от качества записи, акцента и фонового шума.
