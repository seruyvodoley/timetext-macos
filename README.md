# TimeText

Простое приложение для локальной расшифровки видео и аудио на macOS. Перетащите файл в окно, выберите движок и формат. Таймкоды автоматически добавляются к распознанной речи; по желанию приложение создаёт краткое содержание.

## Для пользователя

Скачайте `TimeText-1.2.0-arm64.dmg` со страницы Releases, откройте образ и перетащите приложение в папку «Программы». В приложении по умолчанию выбрана открытая модель GigaAM-v3 e2e-RNNT от SberDevices, настроенная для русской речи. Она работает локально и не отправляет ваши файлы в интернет. Whisper можно выбрать для других языков.

Приложение пока не нотарифицировано Apple. Если macOS не даст открыть его двойным щелчком, нажмите по приложению в «Программах» правой кнопкой мыши и выберите «Открыть» → «Открыть».

Поддерживаются MP4, MOV, M4V, MKV, WebM, AVI, MPEG, WMV, FLV, MP3, WAV, M4A, AAC, FLAC, OGG и OPUS. В панели можно выбрать папку и отдельно сохранить расшифровку в TXT или Word и краткую выжимку в TXT. По умолчанию оба результата сохраняются рядом с исходным файлом. Выжимку создаёт локальная модель Qwen3-0.6B; аудио и текст никуда не отправляются. Модели уже включены в образ, поэтому приложение работает без отдельной установки и загрузки моделей.

Таймкоды GigaAM привязаны к словам и сгруппированы в удобные строки. Длинные аудиозаписи автоматически обрабатываются частями; для краткого содержания большая расшифровка также сводится по фрагментам.

## Сборка

Сборка создаётся на Apple Silicon с macOS 27, Xcode Command Line Tools, Homebrew, Python 3.12, FFmpeg и whisper.cpp:

```sh
brew install python@3.12 ffmpeg whisper-cpp llama.cpp
./Packaging/build_app.sh
./Packaging/create_dmg.sh
```

Скрипт собирает SwiftUI-приложение и локальный runtime GigaAM, включает обе модели и проверяет контрольные суммы. App подписывается локальной ad-hoc подписью; для распространения без предупреждений macOS потребуется Developer ID и notarization.

## Компоненты и лицензии

- Интерфейс TimeText: MIT.

- Мультиязычный резервный движок: [whisper.cpp](https://github.com/ggml-org/whisper.cpp), MIT.
- Краткое содержание: Qwen3-0.6B Q8_0 от Alibaba Cloud, Apache-2.0; модель поставляется внутри приложения.
- Модель Whisper `large-v3-turbo-q5_0`: семейство Whisper, MIT.
- FFmpeg и PyTorch включены в сборку; их лицензии приложены в приложении в `Contents/Resources/Licenses`.

Распознавание зависит от качества записи, шума и особенностей речи; проверяйте важные названия и числа.
