# ТаймТекст

Простое приложение для локальной расшифровки видео и аудио на macOS. Перетащите файл в окно, выберите движок и формат. Таймкоды автоматически добавляются к распознанной речи.

## Для пользователя

Скачайте `ТаймТекст-1.1.0-arm64.dmg` со страницы Releases, откройте образ и перетащите приложение в папку «Программы». В приложении по умолчанию выбрана открытая модель GigaAM-v3 e2e-RNNT от SberDevices, настроенная для русской речи. Она работает локально и не отправляет ваши файлы в интернет. Whisper можно выбрать для других языков.

Приложение пока не нотарифицировано Apple. Если macOS не даст открыть его двойным щелчком, нажмите по приложению в «Программах» правой кнопкой мыши и выберите «Открыть» → «Открыть».

Поддерживаются MP4, MOV, M4V, MKV, WebM, AVI, MPEG, WMV, FLV, MP3, WAV, M4A, AAC, FLAC, OGG и OPUS. Результаты TXT и Word с таймкодами сохраняются рядом с исходным файлом. Модели уже включены в образ; для распознавания интернет не нужен.

Таймкоды GigaAM привязаны к словам и сгруппированы в удобные строки. Длинные аудиозаписи автоматически обрабатываются частями.

## Сборка

Сборка создаётся на Apple Silicon с macOS 27, Xcode Command Line Tools, Homebrew, Python 3.12, FFmpeg и whisper.cpp:

```sh
brew install python@3.12 ffmpeg whisper-cpp
./Packaging/build_app.sh
./Packaging/create_dmg.sh
```

Скрипт собирает SwiftUI-приложение и локальный runtime GigaAM, включает обе модели и проверяет контрольные суммы. App подписывается локальной ad-hoc подписью; для распространения без предупреждений macOS потребуется Developer ID и notarization.
